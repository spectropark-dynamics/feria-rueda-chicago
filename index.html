GRUPO 8 SpectroPark Dynamics

SpectroPark Dynamics

Mecanismo mecatrónico interactivo de parque de diversiones con simulación digital de clasificación automatizada por sensores RGB y principios de Física Fundamental.

Estructuras del Parque Mecánico

🎡 Rueda de Chicago

Construida con paletas de madera multicolores y motor central de giro uniforme. Demuestra el movimiento circular continuo y la conversión de energía eléctrica a mecánica.

🚀 Drop Tower (Torre de Caída)

Estructura en tubo de PVC naranja accionada por motor, poleas y faja dentada. Modela el movimiento rectilíneo vertical, trabajo y energía potencial gravitatoria.

🕹️ Elevador Hidráulico

Mecanismo con jeringas comunicadas y fluido incompresible (agua). Aplica el Principio de Pascal para transmitir fuerza y elevar la plataforma con carga.

📐 Rampa de Plano Inclinado

Pista inclinada junto a la taquilla del parque para el análisis conceptual del peso, la fuerza normal y los coeficientes de fricción.

# SpectroPark Dynamics - Módulo de Control de Rueda de Chicago
# Integración de Clases POO para Sensores RGB y Motores

class SensorRGB:
    def __init__(self, pin_sensor=12):
        self.pin = pin_sensor

    def detectar_color(self, codigo_hex):
        print(f"[Sensor RGB]: Leyendo señal en pin {self.pin} -> Color: {codigo_hex}")
        return codigo_hex

class MotorPasoAPaso:
    def __init__(self, puerto_control="MOT_1"):
        self.puerto = puerto_control
        self.en_movimiento = True

    def detener_en_cabina(self):
        self.en_movimiento = False
        print(f"[Motor {self.puerto}]: Frenado electromagnético activado correctamente.")

    def reanudar_giro(self):
        self.en_movimiento = True
        print(f"[Motor {self.puerto}]: Reanudando giro continuo.")

class RuedaChicago:
    def __init__(self):
        self.sensor = SensorRGB()
        self.motor = MotorPasoAPaso()

    def procesar_cabina_color(self, hex_color):
        color = self.sensor.detectar_color(hex_color)
        if color:
            self.motor.detener_en_cabina()
            return f"Rueda alineada y detenida para el color {color}"

# Ejecución de prueba
parque = RuedaChicago()
resultado = parque.procesar_cabina_color("#FFEA00")
print(resultado)

Preguntas Frecuentes (FAQ)

1. ¿Cómo funciona el elevador hidráulico?
Aplica el Principio de Pascal: al presionar una jeringa, la presión se transmite íntegramente por el agua elevando la segunda jeringa.

2. ¿Qué relación tiene con Python?
El software modela la simulación de detención automática del motor al detectar marcas cromáticas RGB en las cabinas.
